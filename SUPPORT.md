# Support

- Bug reports: [open an issue](https://github.com/Nuanst-GmbH/vscode-litellm/issues/new?template=bug_report.yml).
- In VS Code, run **LiteLLM Proxy: Report Issue** (or click the status-bar item and choose **Report issue**). It opens that form with a diagnostics draft filled in. Nothing is sent until you submit the issue, and you can edit the draft first. [PRIVACY.md](PRIVACY.md) lists every field the draft includes and what it leaves out.
- **LiteLLM Proxy: Troubleshoot (doctor)** writes a local report to the "LiteLLM Doctor" output channel. That report stays on your machine unless you paste it into an issue yourself.
- **LiteLLM Proxy: Recent Requests** lists the last 200 forwarded calls (status, latency, retries) without the prompt body.
