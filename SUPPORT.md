# Support

- Questions and bug reports: [GitHub issues](https://github.com/nuanst-one/vscode-litellm/issues).
- In VS Code, run **LiteLLM Proxy: Troubleshoot (doctor)** and attach the "LiteLLM Doctor" output when you open an issue.
- **LiteLLM Proxy: Recent Requests** lists the last 200 forwarded calls (status, latency, retries) without including the prompt body.
